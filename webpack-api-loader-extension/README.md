# Webpack API Loader

用于授权渗透测试和安全评估的 Chrome 扩展：自动发现 webpack 入口脚本和懒加载分包，抓取 JS 文本并提取 API 接口、URL 与常见敏感线索。

## 功能

- 自动收集当前页面已加载的 `<script>` 和 Performance 资源记录。
- 从 webpack runtime 中识别常见 chunk 映射和 `publicPath`，递归抓取懒加载分包。
- 从所有 JS 包中提取 `fetch`、`axios`、`request`、`url/path/api/endpoint` 等常见调用里的接口。
- 后台代理抓取 JS，降低 CORS、跨域静态资源导致的读取失败。
- 支持导出 JSON、复制接口列表。
- 默认只抓取和分析 JS；勾选“注入脚本到页面”后才会把分包脚本挂到页面中。

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`webpack-api-loader-extension`。
5. 打开授权测试目标页面，点击插件图标后执行“扫描并加载分包”。

## 使用建议

- 建议先用默认模式扫描。默认模式不会主动调用业务 API，只会读取 JS 静态资源。
- “注入脚本到页面”可能触发 chunk 注册或业务前端副作用，只在需要让 DevTools Sources 看到分包时使用。
- 扫描深度越高，发现分包越多，但也更慢；常规站点建议从 `2` 或 `3` 开始。
- 结果里的接口仍需人工确认权限边界、调用上下文和真实参数来源。
